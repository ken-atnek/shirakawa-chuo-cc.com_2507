## コーディング規約

### CSS方針

- Tailwind CSS は使用しない
- スタイルは SCSS で実装する
- 既存のネスト構造や責務を崩さず、最小差分で追記する
- 同階層のセレクタやネストブロック間には、意味のない空白行を入れない
- `npm run lint:style` はチェック用として扱い、必要時のみ `--fix` を明示実行する

### リンク実装方針

- 内部導線は `next/link` を使う
- 外部リンク、`tel:`、PDF など共通化したい導線は `src/components/common/ExternalLink.tsx` を優先する
- 属性指定を各所に散らさない

### 画像実装方針

- TSX では生の `img` タグより `next/image` の `Image` を優先する
- `alt` は見た目説明ではなく意味のある内容を書く

### コンポーネント配置

- 共通パーツは `src/components/common/` 配下
- ページ固有パーツは役割が分かる名前で配置する
- 関連ファイルは極力近い場所に置く

### 命名

- `.tsx` はキャメルケース / パスカルケース
- `.scss` のクラス名は既存命名に合わせる
- 汎用名だけの `Section` `Box` より、役割が分かる名前を優先する
